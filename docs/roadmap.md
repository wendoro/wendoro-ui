## Planned External Engine Bridges & Excluded Runtime Scope

- **Planned External Engines** (via Layer 5 adapter contracts): WebGL/3D scene renderers, full PDF.js paginated canvas renderers, collaborative CRDT rich-text editors (TipTap/ProseMirror), and live map tile engines (Leaflet/MapLibre/Google Maps) via `MapAdapterProvider` & `EditorAdapterProvider`.
- **Intentionally Excluded**: Real database clients, authentication/OAuth flows, payment gateway SDKs, embedded LLM client SDKs, and OS/filesystem installers.
