# Wendoro UI (`@wendoro/ui`) — Enterprise Design System 2.0

**Business, connected.** — Official Website: [https://wendoro.in](https://wendoro.in)

Wendoro UI is the shared design system and modular React component library for the Wendoro software ecosystem, powering **Wendoro Desk**, **Wendoro Flow**, **Wendoro Platform**, **Wendoro Studio**, **Wendoro Insights**, **Wendoro Support**, **Wendoro Commerce**, and **Wendoro People**.

---

## Modular Package Entry Points

`@wendoro/ui` exposes tree-shakeable entry points so standard consumer apps never bundle unused charting modules:

| Subpath | Purpose |
| --- | --- |
| `@wendoro/ui` | Core UI, forms, feedback, navigation, overlays, and enterprise business modules |
| `@wendoro/ui/styles.css` | Standalone compiled Tailwind CSS v4 + design tokens + density + reduced-motion stylesheet |
| `@wendoro/ui/themes/light.css` | Light mode CSS custom properties |
| `@wendoro/ui/themes/dark.css` | Dark mode CSS custom properties |
| `@wendoro/ui/tokens` | Brand, chart palette, semantic color, typography, spacing/density, elevation, motion, and breakpoint tokens |
| `@wendoro/ui/charts` | 18 standard charts + shared container, legend, tooltip, annotations, Intl formatters, and `<table>` fallbacks |
| `@wendoro/ui/charts/advanced` | 12 advanced analytical charts (Funnel, Waterfall, Heatmap, CalendarHeatmap, Treemap, Sankey, BoxPlot, Violin, Histogram, RangeBand, MultiSeriesTimeSeries, MixedAxis) |
| `@wendoro/ui/business` | Analytics, dashboard shell, advanced `DataTable`, Kanban, timeline, calendar grid, workflow, and hierarchy components |
| `@wendoro/ui/hooks` | `ThemeProvider`/`useTheme`, `DensityProvider`/`useDensity`, `useReducedMotion`, `useBreakpoint`, `useId` |

## Design Principles

1. **Brand Discipline**: Primary Yellow (`#FACC15`), Primary Red (`#DC2626`), Deep Black (`#111111`), Crisp White (`#FFFFFF`), Warm White (`#FAFAF7`), Charcoal (`#242424`), Border Gray (`#E5E5E5`), and Muted Gray (`#737373`). Blue, purple, indigo, and teal are excluded.
2. **Accessible Visualization**: Charts pair color tokens with SVG patterns, line dashes, and distinct point markers, provide interactive HTML `<table>` fallbacks, and use native `Intl` formatters.
3. **Scoped Theme & Density Safety**: Storybook previews run `<ThemeProvider forcedTheme={...} disableStorage>` and `<DensityProvider scoped disableStorage>` so previewing themes never mutates host `localStorage`.
4. **Architectural Separation (`@wendoro/ui` vs `@wendoro/sdk`)**: Presentation UI never embeds API clients, auth state, or backend queries. Product apps pass fetched data and loading/error callbacks via props.
